Pre-downloaded season data from [football-data.co.uk](https://www.football-data.co.uk/data.php),
fetched 2026-09-21 while drafting this project, in case the site is
unreachable when you actually work on it.

* `P1-{season}.csv` — Portuguese Primeira Liga.
* `SP1-{season}.csv` — Spanish La Liga.
* Seasons: `2223` (2022/23), `2324` (2023/24), `2425` (2024/25).

Column meanings: see `notes.txt`, saved alongside these CSVs (source:
[football-data.co.uk/notes.txt](https://www.football-data.co.uk/notes.txt)).

**Usage note**: the site states this data is free but *"intended for
private individuals only, NOT commercial or data training products using
automated bots/scrapers/AI."* This is personal, non-commercial learning
material in a private repository — keep it that way; don't redistribute
it or push it to a public mirror, and prefer fetching any additional
seasons yourself via a browser rather than scripting bulk downloads.
